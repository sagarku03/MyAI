# Jarvis AI Changelog

## [3.0.0] - 2026-11-04
### Added
- **Dynamic Quiescence & Settling Engine:** Patient 6.5s polling waiter for low-end device cold starts.
- **Anti-Misclick Guard:** Strict package lock (`expectedPackage = YOUTUBE_PACKAGE`) preventing home screen / HUD taps.
- **Multimodal Visual Screen Perception (`inspect_visual_screen`):** Captures live visual screenshots via Accessibility / MediaProjection and analyzes photos, video thumbnails, and charts using Gemini Multimodal Vision API.
- **Automatic Versioning System:** Version Name `3.0.0`, Version Code `30000`, displayed in General Settings About section and tracked in GitHub sync metadata.

## [2.0.0] - Major Upgrade
